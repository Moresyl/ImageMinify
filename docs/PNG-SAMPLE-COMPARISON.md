质量 82 与 100；关闭 SkipWhenLarger，使实际编码结果不会被原文件替代。

该指标不代替色彩管理或人工视觉检查。

单次调用时间受预热影响且每张只测一次，不据此下性能结论。原始 JSON 与输出保留在本地
`D:/GR/ImageMinify-evidence/{baseline,current,wu-candidate}/`，测量程序位于同目录 `Program.cs`。

## 后续真彩候选改进

保持所有质量门槛，在两个调色板候选均失败后补试有界 RGB 精度真彩候选。
同一组源图重新测量：前两张质量 82 输出和 PSNR 不变；`image3.png` 从无损回退的
466436 字节降至 240695 字节，显示 PSNR 为 44.230 dB，改变 Alpha 的像素数为 0。
质量 100 的三张输出字节和逐像素一致性均不变。

新的第三张结果比原版 103382 字节更大，但显示 PSNR 高于原版 37.568 dB；这是有明确
保真收益和体积代价的折中，不是两项指标都超过原版。输出保留在本地 `rgb-candidate/`。

# 用户手册

本文档提供了 ImageMinify 图片压缩工具的详细使用说明。

## 界面概览

窗口分为左右两栏：左侧是「做什么」，右侧是「怎么做」。

**左栏**

1. **图片来源**：待处理的文件与文件夹列表，支持直接拖入
2. **压缩结果**：每张图片的原始大小、压缩后大小与压缩率
3. **统计条**：已压缩数量、节省空间、平均压缩率、用时

**右栏**

4. **预设**：四组常用参数组合，一键套用
5. **输出格式 / 画质 / 目标大小**：核心压缩参数
6. **尺寸**：缩放方式与数值
7. **处理方式**：元数据、变大跳过、递归子文件夹
8. **输出位置**：压缩后的文件写到哪里
9. **压缩引擎**：当前实际生效的引擎与并行线程数

底部是进度条与「开始压缩」按钮。标题栏右侧的齿轮按钮打开设置中心。

## 基本操作

### 添加图片

三种方式，可以混用：

- **拖拽**：把图片或整个文件夹拖进窗口，松手即添加
- **添加图片**：选择一个或多个图片文件
- **添加文件夹**：选择一个文件夹

支持的输入格式：JPEG (.jpg / .jpeg)、PNG (.png)、WebP (.webp)、BMP (.bmp)。

列表会自动去重：重复路径只保留一份，已被所选文件夹覆盖的单个文件也会被合并掉。每一行右侧的按钮可以单独移除，「清空」按钮清掉整个列表。

### 使用预设

预设是最快的用法，参数直接写在按钮上：

| 预设 | 参数 |
|------|------|
| **网页** | WebP · 质量 80 · 长边 1920 · 清除元数据 |
| **社交媒体** | JPEG · 质量 85 · 长边 2048 · 清除元数据 |
| **存档** | 保持原格式 · 质量 92 · 原始尺寸 · 保留元数据 |
| **极限压缩** | WebP · 质量 60 · 长边 1280 · 清除元数据 |

套用后任意改动一项参数，预设高亮就会自动取消 —— 界面不会声称你还在用某个预设，而实际参数已经不是它了。

### 选择输出格式

- **原格式**：JPEG 仍出 JPEG，PNG 仍出 PNG，只做优化
- **JPEG**：透明区域会合成到白底（JPEG 没有 alpha 通道）
- **PNG**：质量低于 95 时走调色板量化，95 及以上为无损
- **WebP**：同等画质下通常比 JPEG 小 25–35%

覆盖原图模式下格式选择会被锁定为「原格式」——把 PNG 覆盖成 JPEG 会留下一个扩展名与内容不符的文件。

### 调整画质

滑块范围 1–100：

- 数值越高，画质越好，文件越大
- JPEG / WebP 建议 75–85，肉眼基本看不出差别
- PNG 的「质量」控制的是调色板颜色数：95 以下为有损量化，95 及以上跳过量化、逐像素无损

### 按目标大小压缩

不想试参数时，直接填目标大小（KB）：

引擎会在质量 5–100 之间二分查找，找出能落在该体积以内的最高质量。填入非零值后画质滑块自动停用，界面会说明原因。

如果该格式在最低质量下仍然超出目标，程序会给出它能做到的最小文件，并在结果里标注未达成目标 —— 而不是悄悄返回一个远超预算的文件。

### 缩放尺寸

- **保持原尺寸**：不改变像素尺寸
- **限制长边**：限制最长边的像素数，等比缩放
- **按百分比**：缩放到原尺寸的指定百分比

两种模式都只会缩小、不会放大：本来就小于目标尺寸的图片会原样保留。

对于网页和社交用途，缩小尺寸往往比降低画质更有效 —— 4000px 的图放进 1200px 宽的版面，多出来的像素只是体积。

### 处理方式

- **清除元数据**：删除 EXIF、IPTC、XMP 与色彩配置。这也是把照片发到公开场合前抹掉 GPS 坐标的开关
- **跳过变大的图片**：重新编码已经优化过的图片经常会变大，勾选后这类文件保留原件（默认开启）
- **包含子文件夹**：递归处理所选文件夹内的所有层级

未勾选「清除元数据」时程序不会原样保留全部元数据，而是**精简**：只留下相机品牌、型号、软件与拍摄时间，其余（含 GPS、缩略图、镜头序列号等）一并去掉。方向标记会在读取时直接应用到像素上并复位，因此任何看图工具都不会再把图片转向。

### 输出位置

| 方式 | 结果 |
|------|------|
| **加后缀** | 与原文件同目录，文件名加 `_compressed`（后缀可改） |
| **子文件夹** | 原目录下的 `compressed` 文件夹，文件名不变 |
| **指定目录** | 写入所选目录，并保留原有的目录层级 |
| **覆盖原图** | 直接替换原文件，不保留备份 |

覆盖模式不可撤销，也不进回收站。界面会全程标出当前处于覆盖模式，并在每次开始前二次确认。

### 开始压缩

点击「开始压缩」后：

1. 按 CPU 核心数并行编码（上限 16 线程），结果按原顺序实时填入表格
2. 进度条显示已完成数量与当前文件
3. 随时可以点「停止」中断，已经完成的文件不会被回滚
4. 完成后弹出汇总：总数、已压缩、跳过、失败、节省空间与总压缩率

写文件采用先写临时文件再原子替换的方式，因此中途取消或断电不会留下写坏一半的图片。

### 查看结果

结果表格中的每一行：

- **对比原图与压缩后**：打开对比预览。两张图叠在同一块矩形上，分割线左边是原图、右边是压缩后；在图上任意位置按住拖动即可擦除对比，双击回到中间，方向键左右微调。图片下面衬着棋盘格，透明区域一眼可辨，便于确认 alpha 有没有被压平。预览里可以直接打开图片或跳到它所在的位置

  预览支持缩放，这一点对判断画质是必需的：一张 4000px 的照片缩到对话框里显示时，编码器留下的痕迹在缩放过程中已经被重采样掉了，看到的只是「都还行」。滚轮以指针为中心缩放，标题栏的百分比按钮在「适应窗口」与「原始大小」之间切换，两侧的 − / ＋ 按 5% 到 800% 的整档跳。放大到 100% 以上时按最近邻绘制 —— 平滑插值会把振铃和色块这些本该看见的东西糊掉。图片超出画面后按住右键或中键拖动可平移

  快捷键：`←` `→` 微调分割线，`+` `-` 缩放，`1` 原始大小，`0` 适应窗口，`Esc` 关闭
- **在文件资源管理器中显示**：在资源管理器中选中该文件
- 未达到目标大小的行会带一个提示，说明可以改用更小的尺寸或换成 WebP

两个按钮一直显示，不用把鼠标移上去找。其中「对比」只出现在确实有两个文件可比的行上：跳过的行保留的是原文件，失败的行什么都没写出来，而「覆盖原图」把输出写回了输入路径——这三种情况分割线两边会是同一张图。

「导出报告」把整批结果写成 CSV：文件名、原始与输出路径、原始 / 压缩体积、节省字节、压缩率、原始与输出尺寸、实际使用的质量、状态、耗时与错误信息。文件带 UTF-8 BOM，Excel 直接打开不会乱码。

## 压缩引擎

ImageMinify 根据机器上可用的原生工具自动选择最佳链路：

| 格式 | 基础引擎 | 增强引擎（可选） |
|------|----------|------------------|
| PNG | ImageSharp 量化 | imagequant（量化 + 抖动）、oxipng（无损二次优化）|
| JPEG | ImageSharp | MozJPEG / jpegtran（无损重编码，通常再省 5–15%）|
| WebP | ImageSharp | - |

界面右下角的「压缩引擎」区域显示当前实际生效的是哪一个。原生工具全部是可选的 —— 没有它们程序照常工作，只是压缩率略低。

增强引擎均为**无损**后处理：MozJPEG 只重排霍夫曼表与扫描顺序，oxipng 只重新压缩数据流并清理冗余块，一个像素都不会改变。两者都只在结果确实更小时才采用。

## 透明度与元数据

- **PNG 透明**：量化过程会保留 alpha 通道。图标、logo 这类带透明的 PNG 压缩后不会被压成不透明
- **JPEG 透明**：JPEG 没有 alpha 通道，透明区域会合成到白底
- **清除元数据**：JPEG、PNG、WebP 三种格式都会真正写出不含元数据的文件

## 设置中心、语言与主题

点击标题栏右侧的齿轮按钮打开设置中心。语言区可以直接选择 **中文** 或 **English**；主界面、设置页、更新状态、弹窗和错误提示会立即同步，不需要重启，正在进行的压缩也不会中断。外部工具或 Windows 返回的原始技术错误可能保持其原语言，方便按原文检索。

外观区可以直接选择浅色或深色主题。更新区可开启或关闭启动后自动检查，并显示当前版本、检查结果和双语发行说明。检测到新版后点击更新按钮，应用会下载完整性受发布清单保护的安装包并重启安装。

开发目录或手工复制的程序不属于更新器管理范围，设置页会明确提示改用正式安装包；便携版需要保留发布包的目录结构，不能只单独复制 exe。

诊断区可以复制当前环境信息，也可以打开项目主页或问题反馈页面。遇到错误时，弹窗内的“复制错误信息”会复制脱敏后的应用版本、Windows、架构、.NET 运行时和异常链；用户目录、令牌、密码等敏感内容会被替换。

所有压缩参数、界面语言、主题选择、自动更新开关与上次的文件列表都会自动保存，下次启动时恢复。

设置写在 `%AppData%\ImageMinify\settings.json`。保存带防抖延迟以免每拖一下滑块就写一次盘，正常关闭窗口时会立即落盘。写入同样是先写临时文件再替换，所以中途退出不会留下半个 JSON 把所有偏好重置回默认值。

## 提示

- 覆盖模式之外的所有模式都不会动原文件，可以放心试参数
- PNG 量化属于有损压缩，但视觉差异通常不明显；需要逐像素一致时把质量拉到 95 以上
- 已经压缩过的图片二次压缩收益很小，「跳过变大的图片」会替你挡掉这种情况
- 处理超大图片（50MB 以上）时内存占用与耗时都会明显上升，可以先缩尺寸再压

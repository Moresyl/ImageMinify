# 更新日志

所有项目的显著变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
并且本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [3.0.0] - 2026-08-25

### 重大变更

- **移除文件重命名功能**：相关的界面、设置、服务与测试全部删除。压缩工具只做压缩，批量重命名交给专门的工具
- **移除 WPF-UI 依赖**：界面改为自绘控件模板。WPF-UI 的 `ControlsDictionary` 会覆盖全部控件样式（hover 效果、字号等），无法做到统一的排版
- 设置存储从注册表改为 `%AppData%\ImageMinify\settings.json`

### 界面重构

- 左右分栏重排：左侧是来源与结果，右侧是参数，底部是进度与执行
- 全新的浅色 / 深色调色板，可在设置中心切换并持久化
- 全部字号、间距、圆角、图标统一为一套设计变量，按光学对齐调整
- 弹窗改为窗口内的对话层，带有语义级别（信息 / 警告 / 危险）与可选的详情区
- 新增拖拽放置层：拖入时整个来源区给出落点提示
- 新增前后对比预览：两张图叠在同一块矩形上，在图上任意位置按住拖动即可擦除对比，双击回到中间，方向键左右微调。透明区域衬棋盘格，能一眼看出 alpha 有没有被压平
- 对比预览支持缩放：滚轮以指针为中心缩放，5% 到 800% 整档跳，`1` 回到原始大小、`0` 回到适应窗口，超出画面时右键拖动平移。100% 以上按最近邻绘制 —— 平滑插值会把振铃与色块糊掉，而那正是要看的东西。适应窗口的尺寸下，一张 4000px 照片的压缩痕迹在缩放时就已经被重采样掉了，这个功能是判断画质的前提
- 对比舞台改为一个自绘控件（`Controls/ComparisonSurface`）：两张图、棋盘格与分割线由同一段代码绘制在同一个矩形上。此前是一叠 `Image` 元素、宽度靠转换器相乘得出，各层对不齐时界面上没有任何东西会报错。几何计算拆到 `Controls/ComparisonGeometry`，可以脱离窗口单测
- 结果行的「对比」与「定位」按钮常亮，不再只在鼠标划过时出现；只有确实存在两个文件可比的行才有对比按钮
- 自定义窗口边框与标题栏

### 添加

- **完整中英双语界面**：语言入口统一移入设置中心，主界面、设置、更新、弹窗和错误提示即时同步，不重启也不打断正在进行的压缩；选择随其他设置持久化。两种语言写在同一张表的同一行上（`Helpers/Strings.Table.cs`），测试会拦截英文资源中的残留中文以及 XAML 缺失键
- **设置中心**：统一管理语言、浅色 / 深色主题、自动检查更新、版本信息、诊断复制、项目主页与问题反馈
- **应用内更新**：基于 Velopack 和 GitHub Releases 检查版本、展示双语发行说明、下载并重启安装；非安装构建会明确提示安装正式版本
- **可复制错误信息**：运行、报告导出、更新与未处理异常统一生成脱敏诊断报告，包含应用版本、Windows、架构、.NET 运行时和完整异常链
- **目标大小**：填入 KB，引擎在质量 5–100 间二分查找能落在该体积内的最高质量；不可达时给出最小文件并标注未达成
- **压缩预设**：网页 / 社交媒体 / 存档 / 极限压缩，参数写在按钮上，手动改动任一项即取消高亮
- **并行批处理**：按 CPU 核心数并行编码（上限 16），保持结果顺序，可随时取消且保留已完成的结果
- **尺寸缩放**：按长边像素或百分比，只缩小不放大
- **四种输出去向**：加后缀 / `compressed` 子文件夹 / 指定目录（保留目录层级）/ 覆盖原图（带二次确认）
- **变大即跳过**：重新编码变大时保留原文件，但明确要求的格式转换不受此限制
- **元数据精简**：不勾选「清除元数据」时保留相机、型号、软件与时间四项，其余（含 GPS）去掉
- **CSV 报告导出**：逐文件的体积、压缩率、尺寸、实际质量、耗时与错误，带 UTF-8 BOM
- **BMP 直通编码器**，以及递归遍历子文件夹的选项
- 原子写入：先写临时文件再替换，中断不会留下半个文件
- 引擎能力展示扩展到 JPEG 优化器、PNG 量化器、PNG 无损优化器与并行线程数

### 修复

- **窗口整个变黑**：窗口曾为显示 Mica 材质而把自身背景清空，判据是 DWM 对 `DWMWA_SYSTEMBACKDROP_TYPE` 返回 S_OK —— 但 S_OK 只代表 DWM 认识这个属性，不代表它会画。它拒绝绘制时窗口就是一层透明覆在虚无之上（桌面也不会透出来，因为本该在那儿的正是材质），整窗合成到黑色，浅色主题下所有半透明卡片变成灰色。现已彻底移除 Mica 依赖，窗口在任何机器上都保留自己的不透明底色；`PaletteTests.BackgroundBase_IsOpaque` 是它的守卫
- **PNG 透明度被压平**：无 imagequant 时回退的 Octree 量化器只处理 RGB 三通道，会把带透明的 PNG 输出成完全不透明。改为在检测到 alpha 时使用保留四通道的 Wu 量化器，不透明图片仍走 Octree
- **JPEG 元数据未被清除**：ImageSharp 的 `JpegEncoder.SkipMetadata` 并不会移除 EXIF，勾选「清除元数据」的 JPEG 仍可能带着 GPS 坐标写出。改为在写入期间摘除全部配置、写完复原
- oxipng 不再无条件 `--strip all`，只在用户要求清除元数据时才剥离
- 方向标记在读取后立即应用到像素并复位，避免尺寸测量与缩放用错宽高

## [2.1.0] - 2026-03-17

### 优化

- 更换全新应用图标，多尺寸 ICO（16/32/48/256）确保各处正确显示
- 按钮去除 WPF-UI hover 变白效果，使用自定义 ControlTemplate
- 「开始压缩」按钮移入独立的「执行操作」GroupBox，布局更清晰
- 输入控件尺寸统一优化（前缀输入框、ComboBox 等）
- 窗口基类从 FluentWindow 改为 Window，提升兼容性

## [2.0.0] - 2026-03-17

### 重大变更

- **技术栈重构**：从 Python + PyQt5 迁移至 C# + WPF (.NET 10)
- 采用 MVVM 架构（CommunityToolkit.Mvvm）
- 使用 WPF-UI 实现 Fluent Design 风格
- 图像处理改用 SixLabors.ImageSharp

### 添加

- EXIF 元数据读取和保留（MetadataExtractor）
- 设置持久化（Windows Registry）
- 完整的单元测试覆盖
- 原生 imagequant 量化支持（NativeLibraryLoader）
- 独立的 PNG/JPEG/WebP 压缩服务

### 变更

- 项目结构重组为 Models/Services/ViewModels/Views
- 界面升级为 Fluent Design 风格
- 构建系统改为 .NET SDK（dotnet build/publish）

## [1.1.0] - 2026-02-06

### 添加

- PNG 压缩链路升级：优先 imagequant 量化 + Floyd-Steinberg 抖动
- PNG 无损二次优化：支持 oxipng（可用时自动启用）
- JPEG 压缩链路升级：支持 MozJPEG 无损优化（可用时自动启用）
- UI 新增压缩引擎能力展示标签
- UI 支持接入 PyQt-Fluent-Widgets 组件风格（可选）

### 变更

- `requirements.txt` 增加 `imagequant`、`mozjpeg-lossless-optimization`、`PyQt-Fluent-Widgets`
- `setup.py` 同步新增上述依赖
